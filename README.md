# CryptoAnalysis: Hypergraph Cipher Breaker

> **Демонстрация полного криптоанализа линейного шифра на основе гиперграфов**  
> Восстановление матрицы преобразования над GF(2), вычисление обратной матрицы и дешифрование без знания секретного ключа.
---

## Описание

Проект реализует **атаку по известному открытому тексту** (Known-Plaintext Attack) на шифр, использующий линейное преобразование на базе гиперграфов.  
Поскольку шифр **полностью линеен над полем GF(2)**, достаточно зашифровать базисные векторы (единичные биты), чтобы восстановить полную матрицу преобразования. Обратная матрица вычисляется методом Гаусса-Жордана, что позволяет мгновенно дешифровать любые сообщения.

Проект предназначен для:
-  Обучения основам линейного криптоанализа
-  Тестирования криптографических примитивов на уязвимости
-  Демонстрации принципов построения стойких шифров

| Функция | Описание |

|  **Статистические тесты** | 100+ итераций с верификацией целостности и отчётом об успехе |
|  **Анализ безопасности** | Автоматический вывод уязвимостей и рекомендаций по защите |
|  **Совместимость** | Java 11+, Maven, чистый код без внешних зависимостей (кроме `org.reminstant.*`) |
